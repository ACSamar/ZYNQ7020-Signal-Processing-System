# SignalAPP_V1_2 G 题周期信号测量程序

该应用用于 2026 赛区赛 G 题《周期信号测量分析装置》的 ADC0 首轮联调。

## 当前功能

1. ADC0 以 35 MSPS 采集 115192 个双通道打包数据字。
2. DAC0 启动时输出 0 V 控制电平，DAC1 保持关闭。
3. 511 抽头低通滤波后 7 倍抽取到 5 MSPS。
4. 执行 16384 点 FFT，频率栅格约为 305.18 Hz。
5. 检测 5 kHz 至 800 kHz 范围内最多 3 根谐波谱线。
6. 输出基频、峰峰值、真有效值、THD和各谱线峰值幅度。
7. 输出 ADC 原始最小码、最大码、峰峰码和削顶状态。
8. 输出单次采集和分析总耗时。

周期信号分析器源码和主机回归测试已经完整放入本应用目录，不再依赖
其他 Vitis 应用目录，删除旧测试工程后仍可独立构建。

真有效值使用已经识别并完成各自 FIR 频响补偿的分量峰值计算。
对于基波与谐波组成的周期信号，采用
`sqrt((peak1^2 + peak2^2 + peak3^2) / 2)`。未检出的分量不参与
计算，1 MHz 以上单频干扰不会进入真有效值结果。
第三问输入 `Ub+Uj` 时，串口与屏幕的 `rms`、`tVrms` 均表示
滤除 `Uj` 后的 `Ub` 真有效值。

## 串口

PS UART1 使用 115200、8N1。程序上电后自动连续测量。

启动信息精简为两行：

```text
=== ACM2108V2 G Analyzer ===
CFG ADC0 raw=35000000Hz fs=5000000Hz fft=16384 d=7 cal=7813uV/code
```

每帧结果只占一行：

```text
M s0 v1 c0 h0 raw39@130.598 n3 f 30.005,59.997,150.000k a 23.005,11.756,5.663m pp60.666 rms18.702 thd56.7219% t49ms
```

`s` 是分析状态，`v` 是结果有效标志，`c` 是削顶标志，`h` 是
结果保持标志。`raw` 为 ADC 峰峰码和均值，`n` 为分量数量，`f`
使用 kHz，`a`、`pp` 和 `rms` 使用 mV，`thd` 使用百分比，`t` 使用 ms。串口不再
输出每个分量的相位。

程序允许单基波、基波加 1 个谐波或基波加 2 个谐波进入稳定跟踪，
并要求连续 3 帧频率组合一致后才建立或者切换稳定结果。单帧
异常时继续输出最近一次稳定结果并置 `h1`，信号源频率改变后通常
在约 200 ms 内完成切换，候选结果不连续时会适当延长。首次锁定
前输出 `Q lock x/3`。每次测量后的额外等待时间为 10 ms。

存在 3 个分量时，程序把第三频率与最接近的整数次基波频率进行
比较。绝对误差超过 1 kHz 的候选帧不会更新稳定结果，串口继续
输出上一帧并置 `h1`。

## 串口屏显示

PL UARTLite 位于 `0x42C00000`，使用 P14/P15、115200、8N1 和
Nextion/TJC 的 `FF FF FF` 命令结束符。TJC1060X570011 界面按
1024×600 分辨率设计，界面提供以下页面：

- `q1`：题目第 1 问，开机默认页面，使用 20.4 倍档。
- `q2`：题目第 2 问，使用 20.4 倍档。
- `q3`：题目第 3 问，自动切换 10.4 倍抗干扰档。

三个页面的曲线控件均设置为 `x=112`、`y=30`、`w=800`、`h=300`，
水平方向 20 格、垂直方向 7 格。频谱横轴显示相对基波的谐波次数，
并根据当前最高次数自动选择整数刻度，纵轴根据当前最高峰值选择
整数 mV 刻度。谱线位置按谐波次数计算，高度按电压刻度计算。波形横轴显示 1 个或
3 个基波周期对应的微秒时间，纵轴显示以零点为中心的毫伏刻度。
PS 使用 `xstr` 命令绘制 11 个横轴数字和 8 个纵轴数字，字体资源
ID 为 0。横轴可用区域为屏幕纵坐标 330 至 441，数字框靠近曲线
底部，实际使用 `y=332`、`h=18`。程序不发送 `fill` 或 `line`。
PS 缓存当前坐标量程，量程不变时只刷新曲线数据，不重复发送刻度
命令。分析器使用 5 kHz 至 800 kHz
有效测量带宽，以隔离 1 MHz 以上单频干扰。波形和频谱只在检测到
分量数量、频率、幅值或相对相位发生有效变化时更新。
三个分量相对基波的整数次数分别发送到串口屏文本控件 `tT0`、
`tT1` 和 `tT2`，缺少的分量显示 `--`。
THD 发送到文本控件 `tTHD`，显示四位百分比小数。THD 使用完成幅频
补偿的分量峰值计算，第三问中的 1 MHz 以上干扰不进入计算。

屏幕按钮向串口发送下列 ASCII 文本并以换行或 `FF FF FF` 结束：

```text
MODE Q1
MODE Q2
MODE Q3
WAVE1
WAVE3
SPECTRUM
```

`MODE Q1` 和 `MODE Q2` 使 DAC0 输出 0 V 并使用 20.4 倍档；
`MODE Q3` 使 DAC0 输出高电平并使用 10.4 倍档。每次模式切换
都会清空旧结果并重新执行三帧锁定。三个页面均包含参数文本和
组件 ID 1、通道 0 的 800 点波形控件。参数每 4 个测量帧刷新一次，
波形和频谱采用事件触发刷新。稳定信号期间不会重复发送曲线数据。
页面切换由串口屏按钮执行，PS 只处理模式、增益和测量状态，不发送
`page q1`、`page q2` 或 `page q3`。波形和频谱数据在发送前统一
反转 800 点横坐标，以适配当前串口屏曲线显示方向。

PS UART1 也接受相同命令，便于未连接屏幕时调试。旧的 `PARAM`、
`WAVE5`、`GAIN 20.4` 和 `GAIN 10.4` 命令继续保留用于调试。
DAC0 的 0 V 使用中点码 `128`，高电平使用满量程码 `255`。N17
保持寄存器上电默认低电平，应用程序不再切换该引脚。
串口驱动在等待曲线透明传输确认包期间会缓存同时到达的按钮命令，
避免 `MODE Q3` 被确认包接收流程丢弃。

最多同时输出 3 个周期信号分量，对应题目规定的基波与 1 个或者
2 个谐波分量。

正式答疑约束已经写入算法：

- 每帧稳定结果至少包含基波和 1 个谐波，单分量候选不会建立或者
  切换稳定结果。
- 题目规定每个频率分量的峰值幅度不低于 5 mV。为吸收前端增益、
  滤波补偿和量化误差，应用层候选检测门限放宽到 `2000 uV`。
- 该阈值使用题目规定的分量峰值。信号源采用峰峰值设置时，
  `10 mVpp` 对应 `5 mV` 峰值。内部2 mV门限只用于避免漏检，
  不改变题目规定的5 mV最小测试分量。
- FFT 插值频率距离最近的 500 Hz 参考网格不超过 125 Hz 时，
  向网格校正 50%。距离超过 125 Hz 时保留原始插值频率。
- 支持最高 160 次谐波，以覆盖 5 kHz 基波与 800 kHz 谐波的
  边界组合。
- 谐波候选相对最近整数次基波的绝对频率误差不得超过 1 kHz。
- 幅度采用输入端到端双档标定。20.4 倍档使用 `1896 uV/code`，
  10.4 倍档使用 `3785 uV/code`。10.4 倍系数采用同一无干扰信号
  在 Q1/Q2 与 Q3 间的幅值和有效值联合校准结果。
- `GAIN 20.4` 将 DAC0 设为 0 V 并使用 20.4 倍档校准；
  `GAIN 10.4` 将 DAC0 设为高电平并使用 10.4 倍档校准。切换后
  测量跟踪器重新锁定。旧命令 `GAIN 20.8` 保留为 20.4 倍档兼容
  别名。

字段说明：

1. `f0_hz_x100` 除以 100 得到 Hz。例如 `9999578` 对应
   `99995.78 Hz`，约为 100 kHz。
2. `upp_uv` 除以 1000 得到 mVpp。
3. `urms_uv` 除以 1000 得到 mVrms。
4. `peak_uv` 是题目所用正弦分量峰值，除以 1000 得到 mV。
5. `clipped=1` 表示 ADC 出现接近 0 或 255 的码值，当前幅值结果不可用于校准。
6. `status=0` 表示分析成功。

## 初次复测

四组信号应分别测试：

1. 10 kHz，1 Vpp。
2. 20 kHz，500 mVpp。
3. 50 kHz，250 mVpp。
4. 40 kHz，250 mVpp。

每次只输入一组单频信号。先观察 `raw_min`、`raw_max` 和 `clipped`。出现削顶时降低输入幅度。正式 G 题测试范围为总输入 50 mVpp 至 250 mVpp。

## 电压校准

`app/g_measurement_config.h` 中的 `G_INPUT_MICROVOLTS_PER_CODE` 当前为 7813，按 2.000 Vpp 对应 256 码估算。

实际校准步骤：

1. 输入已用示波器确认的 100 kHz、250 mVpp 正弦波。
2. 记录 `raw_p2p`。
3. 计算每码微伏值：`250000 / raw_p2p`。
4. 修改 `G_INPUT_MICROVOLTS_PER_CODE`。
5. 重新构建后检查 `upp_uv` 是否接近 250000。

前端增益或量程切换后需要分别保存校准系数。
